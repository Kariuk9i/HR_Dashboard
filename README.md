## Project Objectives – Summary

The project aims to analyse Acacia Services Ltd's HR workforce data using Microsoft Excel to generate meaningful insights that support effective human resource management.

Specifically, it focuses on workforce distribution, employee retention and resignation trends, salary analysis, employee performance, job satisfaction and workload patterns. Through data cleaning, analysis and interactive dashboard development, the project seeks to identify workforce trends and provide data-driven recommendations to improve employee retention, engagement and organisational decision-making.
